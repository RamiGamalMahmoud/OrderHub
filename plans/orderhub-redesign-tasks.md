## 0) Locked global rules (apply to every task)

1. **Full design fidelity** to the template — colors/spacing/radii/typography.
2. **Tailwind first**; new CSS kept to a minimum; **delete unused legacy CSS** with every task.
3. **MudBlazor only where it provides functionality**; otherwise plain HTML + Tailwind. Style MudBlazor components via `mud-blazor-overrides.css`.
4. **Zero JavaScript** — all interaction via Blazor / MudBlazor components.
5. **Responsive design mandatory** for every screen (sm/md/lg/xl breaks as in templates).
6. **Always Latin digits** via `CultureInfo.InvariantCulture`.
7. **Unified page scaffold**: breadcrumb (Home / Section / Current in brand color) + h1 + count badge + actions area.
8. **Unified table footer on every table**: right side "Showing A-B of C items" + rows-per-page selector 10/25/50; left side square navigation buttons (first/prev/page numbers/next/last; current = brand-50 background with brand-200 border).
9. **No commit unless explicitly requested** by the owner.
10. **(REVISED — real weights available)** Tajawal is now a full static multi-weight set (200/300/400/500/700/800/900) in `wwwroot/fonts`. Template typography weights are used as designed (`700`/`800`/`900` headings, `600` labels, `500` emphasis); CSS `600` and `100` requests resolve to the nearest real face (Bold / ExtraLight files).
11. **(Evolved compact card language — from the `create-product.html` pass; apply to every remaining non-template page/dialog)** page-level list cards stay `rounded-2xl` under `PageScaffold`; inner section/dialog cards are `rounded-xl border border-slate-200/90 bg-white p-4 sm:p-5 shadow-xs` with a `pb-3 mb-3 border-b border-slate-100` header = 32px tonal icon tile (`bg-<tone>-50 text-<tone>-600 border-<tone>-100`) + `text-sm font-bold text-slate-800` title + `text-[11px] text-slate-600` helper. Tone map: blue = basic data, indigo = categories, teal = contact/suppliers, purple = attributes, amber = «مطلوب» chips; counters are `text-[11px] font-bold` tonal pills. Text: headings `slate-800/900`, body `slate-600`, values `slate-700/800`. Dialogs follow `CityEditorDialog` (icon header + close, `bg-slate-50/70` body with white section cards, footer readiness dot + إلغاء/حفظ) and use inline red/amber banners instead of `MudAlert`. Compact actions: `text-xs font-bold`, `rounded-lg`, brand-600 filled primary with `shadow-sm shadow-brand-500/25`.
